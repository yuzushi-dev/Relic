# Citing Relic

## Status

A paper describing the system design and its theoretical grounding is in preparation. This page will be updated when it is available.

## Citing the software

Until a citable paper is published, use the GitHub repository:

```bibtex
@software{relic2025,
  author    = {yuzushi-dev},
  title     = {Relic: Runtime Governance and Longitudinal Modeling for Reflective Agents},
  year      = {2025},
  url       = {https://github.com/yuzushi-dev/Relic},
  note      = {OSS Alpha, AGPL-3.0}
}
```

## CITATION.cff

A `CITATION.cff` file is provided at the repository root; GitHub renders it as a "Cite this repository" widget, and most reference managers can import it directly.

## If you build on Relic

If you publish work that uses Relic, we ask that you:

1. Cite the software (and the paper, once published).
2. Clearly describe any modifications you made to the system.
3. Report the version or commit hash you used.
4. Be explicit about the limitations described in [Limitations](limitations.md) that apply to your use case.

Point 4 is particularly important for academic publications. Relic's facet estimates are not validated psychometric measurements. Papers that treat them as such without appropriate qualification will misrepresent the system's claims.
