# Behavior Constraints Panel Specification

## Status

Normative specification for PR27D.

## Purpose

Display label-stripped behavior constraints generated by PR32 and enforced by PR30.

## Required Fields

| Field | Description |
|---|---|
| patch_id | Unique patch identifier |
| source_signal_ids | Source signal IDs (researcher view only) |
| contains_sensitive_label | Must be false in runtime preview |
| pacing | Pacing constraint value |
| proactivity | Proactivity constraint value |
| warmth | Warmth constraint value |
| emotional_intensity | Emotional intensity constraint |
| media | Media constraint settings |
| diegetic_life_fragments | Diegetic life fragment settings |
| advice_policy | Advice policy settings |
| external_support_wording | External support wording |
| forbidden_language_classes | Forbidden language classes |
| expires_at | Expiration timestamp |
| review_required | Whether review is required |
| status | Current patch status |

## Gumi Runtime Preview Rule

**CRITICAL**: The panel may show source signal IDs to researchers, but the runtime preview MUST show only what Gumi receives.

### Allowed Runtime Preview

```json
{
  "behavior_constraints": {
    "pacing": "slow",
    "proactivity": "reduced",
    "forbidden_language_classes": ["diagnostic_language"]
  }
}
```

### Forbidden Runtime Preview

```json
{
  "safety_signal": "sleep_energy_context"
}
```

## Block Conditions

| Condition | Trigger |
|---|---|
| BLOCKED_SOURCE_LABEL_IN_RUNTIME | Source safety label appears in Gumi preview |
| BLOCKED_UNSTRIPPED_CONSTRAINT | Constraint with sensitive label visible to Gumi |

## Required Actions

- approve patch
- reject patch
- expire patch
- view audit
- preview runtime context

## Acceptance Criteria

- [ ] Runtime preview shows only label-stripped constraints
- [ ] Source safety label is NOT shown in Gumi preview
- [ ] All required fields displayed
- [ ] Actions available: approve, reject, expire, view audit, preview
