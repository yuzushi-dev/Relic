# Gumi Bootstrap Outputs

Each subject bootstrap writes these subject-local JSON files:

- subject_baseline.json
- relational_comfort_profile.json
- diegetic_tolerance_profile.json
- boundary_policy.json
- gumi_generation_constraints.json
- gumi_profile_candidate.json
- sweet_spot_report.json
- bootstrap_manifest.json
- first_contact_candidate.json
- hermes_profile_manifest.json

Every output includes schema_version, version, created_at, subject_id, and experiment_id.

Gumi-scoped outputs include gumi_instance_id. Hermes provisioning output includes hermes_profile_id.
