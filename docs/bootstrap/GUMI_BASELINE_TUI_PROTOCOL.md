# Gumi Baseline TUI Protocol

The bootstrap TUI is a researcher-mediated profile creation flow. It is separate from Relic installation.

Required order:

1. Create or select one subject in one experiment.
2. Record consent and communication scope before any delivery or first-contact decision.
3. Collect the subject baseline using researcher-facing questions.
4. Store normalized PR28 baseline dimensions as low-confidence initial calibration.
5. Derive boundary and risk policy before Gumi candidate generation.
6. Generate a subject-scoped Gumi candidate and require researcher review.

The TUI must not ask the subject to choose Gumi's personality. It may explain that answers configure the available Relic interaction.

Baseline values are initial calibration data only. They are not clinical, diagnostic, or psychometric truth.
