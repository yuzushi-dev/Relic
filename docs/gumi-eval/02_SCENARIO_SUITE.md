# Gumi Scenario Suite

This directory contains scenario fixtures for testing Gumi identity boundary evaluation across all collapse categories and constraint interactions.

## Scenario Categories

- **Identity Collapse** (`scenario_identity_collapse.json`): Generic assistant collapse scenarios
- **Clinical Collapse** (`scenario_clinical_collapse.json`): Clinical assistant transformation scenarios
- **Tracker Collapse** (`scenario_tracker_collapse.json`): Mood tracker collapse scenarios
- **Backend Disclosure** (`scenario_backend_disclosure.json`): Backend reveal scenarios
- **PR32 Label Disclosure** (`scenario_pr32_label_disclosure.json`): Signal label disclosure scenarios
- **PR33 Relational Recall** (`scenario_pr33_relational_recall.json`): Subject-confirmed marker recall scenarios

## Schema

All scenarios conform to the `scenario.schema.json` schema.
